📊 Price Drift Tracker

📌 Project Overview
Price Drift Tracker is a data analytics project developed to compare product prices across three e-commerce platforms: Amazon, Flipkart, and Croma.

The main objective is to analyse price variations, identify the cheapest platform for each product, and estimate potential customer savings.

**Note:** This project uses simulated price data for analytical and educational purposes. It does not contain real-time marketplace prices.

🎯 Project Objectives
- Compare product prices across multiple platforms.
- Identify the cheapest platform for each product.
- Analyse price variations across product categories.
- Identify products with the highest price differences.
- Build an interactive Power BI dashboard.

🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- SQLite
- Power BI
- Jupyter Notebook

📂 Dataset Information
- Total Records: 1,000
- Total Products: 100
- Categories: 5
- Platforms: 3
- Date Range: January 2026 – June 2026

⚙️ Project Workflow
1. Dataset preparation
2. Data cleaning using Python and Pandas
3. Exploratory Data Analysis (EDA)
4. SQL analysis using SQLite
5. Latest price comparison across platforms
6. Power BI dashboard development
7. Business insights generation

📈 Key Findings
- Flipkart had the lowest recorded price for 42 products.
- Amazon had the lowest recorded price for 39 products.
- Croma had the lowest recorded price for 19 products.
- Average price difference: ₹1,333.
- Total potential savings: ₹1,33,300.

📊 Power BI Dashboard
The dashboard includes:
- Total Products KPI
- Average Price Difference KPI
- Total Potential Savings KPI
- Cheapest Platform Comparison
- Category-wise Price Comparison
- Top 10 Products by Price Difference
